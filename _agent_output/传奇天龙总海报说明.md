## 五、生成方式与修改指引

- 海报用 **Python PIL 程序合成**（历次在 Bash 内联执行，未存独立 .py 脚本；按本说明第二节坐标可直接重建）。
- 每次修改后：重新合成 → 保存为 `_agent_output/传奇天龙总海报.png` → 上传云端 → present_files 交付 + 回复正文内嵌展示。

### 常见修改点
- **改宣传语/QQ 号**：顶部宣传语区（第二节第 1 项）
- **换天龙宣传图**：替换 guide1/guide2（`/tmp` 会被清理，回源 URL 见 `TASK_NARRATIVE`/附件记录，或直接由用户重新提供）
- **增删传奇图标**：操作 `assets/cq-icons/` 目录（文件名=游戏名），注意底部收尾文案不写死数量，无需同步改
- **换二维码**：替换 `assets/group-qr.png`，同时重拼海报二维码区域
